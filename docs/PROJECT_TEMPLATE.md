# Lylink Project Template

Projects should include the files and directories appropriate to their scope, conventions, and technology.

At minimum, a project should include a `README.md`, an appropriate `LICENSE`, a `.gitignore`, and a `docs/` directory containing `CONTRIBUTING.md`. Additional documentation should generally be placed in `docs/`.

```text
lylink-y/<project-name>/
├── README.md
├── LICENSE
├── .gitignore
└── docs/
    └── CONTRIBUTING.md
```

Lylink projects may use different licenses depending on their needs. MIT is the recommended default for open-source projects without a specific licensing requirement.

## README

The project README is the starting point for anyone encountering the repository for the first time. It should state clearly and succinctly:

* What the project is, why it exists, and what it does.
* How to install, configure, and use the project.

It should also contain links to further documentation, especially the contributing guidelines.
