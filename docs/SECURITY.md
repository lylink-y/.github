# Security

We take security issues seriously and appreciate responsible disclosure.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues or discussions.

Instead, use the repository's private security reporting mechanism. If a project does not provide one, contact the relevant Keeper or a Warden privately.

Please include:

* A description of the vulnerability
* The affected project, repository, and version or commit, if applicable
* Steps to reproduce the issue
* The potential impact
* Any suggested mitigation, if you have one

You may include supporting material such as logs, screenshots, or a proof of concept where appropriate.

For projects with their own security policy, follow the instructions provided there.
