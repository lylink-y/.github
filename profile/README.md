# Lylink

It has long been said that the best way to learn is by doing. **Lylink is built on that belief.**

We are an open-source collective for people who want to grow by building and maintaining projects together.
We do it because we enjoy it; because it is worth the trouble.

Some of our projects will be essentially educational: opportunities to experiment and put theory into action.
Others, we hope, will grow beyond that into tools and resources that make a difference out there in the world.

Like the flower from which we take our name and identity — the *Lycoris radiata* —
we hope to grow where others might not expect us to, and through even the heaviest of rains.
